## 문제

TV 시청자가 리모컨으로 채널을 이리저리 돌린다.
현재 보고 있는 채널 번호는 처음에 **1번**이다.
채널은 **1번부터 N번까지** 있고, 순환한다(N번 다음은 1번, 1번 이전은 N번).

리모컨 조작이 순서대로 주어진다. 각 조작은 다음 중 하나다.

### 1) `UP`
채널 번호를 1 올린다. 현재가 N번이면 1번으로 순환한다.

### 2) `DOWN`
채널 번호를 1 내린다. 현재가 1번이면 N번으로 순환한다.

### 3) `SET x`
채널을 x번으로 바로 이동한다. (1 <= x <= N 보장)

### 4) `BACK`
**직전에 보던 채널**로 되돌아간다.
- 즉, 바로 이전 조작이 끝난 뒤의 채널이 아니라,
  "이번 조작 직전에 내가 있던 채널"로 돌아간다.
- 맨 처음(아무 조작도 안 한 상태)에서 `BACK`이 나오면 무시한다(채널 유지).
- `BACK` 자체도 하나의 조작이다. `BACK` 다음에 또 `BACK`이 오면,
  다시 그 직전 채널로 돌아간다(= 왔다 갔다 토글이 됨).

> 힌트: `BACK`은 "바로 직전 채널 하나"만 기억하면 된다. 전체 히스토리 스택이 아니다.

## 시청 시간 집계

모든 조작이 끝난 뒤, **가장 많이 "머문" 채널**을 출력한다.
- "머물렀다"의 정의: 각 조작을 처리할 때마다,
  **그 조작 직후의 현재 채널**에 방문 횟수 +1 을 기록한다.
- 시작 채널(1번, 아무 조작 전 상태)도 **방문 1회**로 친다.
- 가장 방문 횟수가 많은 채널 번호를 출력한다.
- 동점이면 **채널 번호가 작은 것**을 출력한다.

## 입력

- 첫 줄: `N Q` (2 <= N <= 1,000,000, 1 <= Q <= 200,000)
- 다음 Q줄: 위 네 조작 중 하나 (`SET x`만 인자 있음)

## 출력

- 가장 많이 방문한 채널 번호 (동점이면 작은 번호) 한 줄

## 예시 입력

```
5 6
UP
UP
SET 5
BACK
DOWN
UP
```

## 예시 출력

```
1
```

## 예시 해설

초기 채널 = 1 (방문 기록: {1:1})

| 조작 | 처리 후 채널 | 직전 채널(BACK용) | 방문 기록 |
|------|-------------|------------------|-----------|
| 시작 | 1 | - | 1:1 |
| UP   | 2 | 1 | 1:1, 2:1 |
| UP   | 3 | 2 | 1:1, 2:1, 3:1 |
| SET 5| 5 | 3 | ...+ 5:1 |
| BACK | 3 | 5 | 3:2 |
| DOWN | 2 | 3 | 2:2 |
| UP   | 3 | 2 | 3:3 |

최종 방문 횟수: 1->1, 2->2, 3->3, 5->1
가장 많은 건 채널 3 (3회).

## 핵심 체크리스트

- 순환 처리: UP에서 N -> 1, DOWN에서 1 -> N
  (모듈러 쓸 때 채널이 1-based인 것 주의! `cur % N + 1` 같은 식 조심)
- BACK: "직전 채널 하나"만 기억. 변수 하나면 충분 (스택 불필요)
- BACK 연속 시 토글 동작
- 방문 횟수 저장: N이 최대 100만 -> 배열 `int[N+1]` 또는 HashMap
  (실제 방문하는 채널 수는 Q+1개 이하이므로 HashMap이 메모리엔 유리)
- 시작 채널 1번도 방문 1회로 카운트
- 동점 시 작은 번호
- Q가 20만 -> BufferedReader / StringBuilder 사용
