# 167. Two Sum II - Input Array Is Sorted

**난이도:** Medium

## 문제

**1-indexed** 정수 배열 `numbers`가 **오름차순(non-decreasing)으로 정렬되어** 주어진다.
두 수의 합이 `target`이 되는 두 원소를 찾아, 그 인덱스 `[index1, index2]`를 반환하라 (`index1 < index2`).

- 정답은 항상 정확히 하나만 존재한다.
- 같은 원소를 두 번 사용할 수 없다.
- **추가 공간을 O(1)만 사용해야 한다.**

## 예제

### Example 1
```
Input: numbers = [2,7,11,15], target = 9
Output: [1,2]
Explanation: 2 + 7 == 9 이므로 index1 = 1, index2 = 2
```

### Example 2
```
Input: numbers = [2,3,4], target = 6
Output: [1,3]
```

### Example 3
```
Input: numbers = [-1,0], target = -1
Output: [1,2]
```

## 제약조건 (Constraints)

- `2 <= numbers.length <= 3 * 10^4`
- `-1000 <= numbers[i] <= 1000`
- `numbers`는 오름차순으로 정렬되어 있다
- `-1000 <= target <= 1000`
- 유효한 정답은 오직 하나만 존재한다

## 왜 이 문제인가

**1번 Two Sum과 짝을 이루는 대조군.** 여기서는 투 포인터가 정답이다.
1번에서는 왜 안 됐는지, 여기서는 왜 되는지 그 차이를 말로 설명할 수 있어야 한다.
