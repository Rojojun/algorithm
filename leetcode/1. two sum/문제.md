# 1. Two Sum

**난이도:** Easy

## 문제

정수 배열 `nums`와 정수 `target`이 주어졌을 때, 두 수의 합이 `target`이 되는 **두 원소의 인덱스**를 반환하라.

정답은 항상 **정확히 하나만** 존재한다고 가정하며, 같은 원소를 두 번 사용할 수는 없다.

반환하는 인덱스의 순서는 상관없다.

## 예제

### Example 1
```
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: nums[0] + nums[1] == 9 이므로 [0, 1]을 반환한다.
```

### Example 2
```
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

### Example 3
```
Input: nums = [3,3], target = 6
Output: [0,1]
```

## 제약조건 (Constraints)

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 유효한 정답은 오직 하나만 존재한다
