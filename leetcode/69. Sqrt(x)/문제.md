# 69. Sqrt(x)

**난이도:** Easy

## 문제

정수 `x`가 주어졌을 때, `x`의 제곱근의 정수 부분(integer square root)을 반환하라.

결과값의 소수 부분은 버리고(truncated) 정수 부분만 반환해야 한다.

**참고:** 내장 제곱근 함수(`pow(x, 0.5)` 등) 사용은 허용되지 않는다.

## 예제

### Example 1
```
Input: x = 4
Output: 2
```

### Example 2
```
Input: x = 8
Output: 2
Explanation: 8의 제곱근은 2.82842...이며, 소수 부분은 버려지므로 2를 반환한다.
```

## 제약조건 (Constraints)

- `0 <= x <= 2^31 - 1`
