# 242. Valid Anagram

**난이도:** Easy

## 문제

두 문자열 `s`와 `t`가 주어졌을 때, `t`가 `s`의 **애너그램**이면 `true`, 아니면 `false`를 반환하라.

애너그램이란 어떤 문자열의 문자들을 재배열해서 만든 문자열을 말한다.
즉, 두 문자열이 **같은 문자를 같은 개수만큼** 가지고 있으면 애너그램이다.

## 예제

### Example 1
```
Input: s = "anagram", t = "nagaram"
Output: true
```

### Example 2
```
Input: s = "rat", t = "car"
Output: false
```

## 제약조건 (Constraints)

- `1 <= s.length, t.length <= 5 * 10^4`
- `s`와 `t`는 소문자 영문자로만 구성된다

## Follow-up

입력에 유니코드 문자가 포함된다면 풀이를 어떻게 바꿔야 하는가?

## 왜 이 문제인가

**해시맵 카운팅 입문.** 지금까지의 "완탐 → 최적화" 습관을 그대로 쓸 수 있는 문제다.

세 가지 풀이를 **전부** 작성해보고 비교할 것:
1. 정렬 후 비교 — `O(n log n)`
2. 길이 26 배열 카운팅 — `O(n)`, 소문자 전제
3. 해시맵(`dict` / `HashMap`) 카운팅 — `O(n)`, 유니코드도 가능

2번과 3번의 관계를 이해하는 게 핵심이다. **배열도 "키가 정수로 제한된 해시맵"**이다.
지금까지 배열만 써 왔다면, 이 문제가 그 배열을 해시맵으로 일반화하는 다리다.
