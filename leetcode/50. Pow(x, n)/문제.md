# 50. Pow(x, n)

**난이도:** Medium

## 문제

`x`를 `n` 제곱한 값(x^n)을 계산하는 `pow(x, n)`을 구현하라.

**참고:** 내장 거듭제곱 연산자(`**`)나 `math.pow` 사용은 허용되지 않는다.

## 예제

### Example 1
```
Input: x = 2.00000, n = 10
Output: 1024.00000
```

### Example 2
```
Input: x = 2.10000, n = 3
Output: 9.26100
```

### Example 3
```
Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2^-2 = 1 / 2^2 = 1 / 4 = 0.25
```

## 제약조건 (Constraints)

- `-100.0 < x < 100.0`
- `-2^31 <= n <= 2^31 - 1`
- `n`은 정수
- `x != 0` 이거나 `n > 0` (0^0, 0의 음수 제곱은 입력으로 주어지지 않음)
- `-10^4 <= x^n <= 10^4`
